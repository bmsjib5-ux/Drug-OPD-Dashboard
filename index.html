opitemrece ↔ opd_presc_machine (เทียบด้วย hos_guid)
ยังไม่เชื่อมต่อ
เปิดไฟล์นี้ตรงจากดิสก์ (file://) จะดึงข้อมูลจาก HOSxP ไม่ได้ — ให้ดับเบิลคลิก start.bat แล้วใช้ลิงก์ MAIN URL (http://IP-เครื่อง:8797/) ที่หน้าต่าง start.bat แสดง

รายชั่วโมง

สั่งใน opitemrece (rxtime) เข้าเครื่อง (modify_datetime) ตัวเลขใต้แท่ง = เวลารอเฉลี่ยจากเข้าเครื่องถึง gateway (นาที)

รายการ

วาง BMS Session ID แล้วกดเชื่อมต่อ ระบบจะดึง opd_presc_machine (ตามวันที่ modify_datetime) และ opitemrece ของยาที่ตั้งเข้าเครื่อง (ตาม vstdate) มาเทียบกันด้วย hos_guid — อ่านอย่างเดียว ไม่เขียนฐานข้อมูล
